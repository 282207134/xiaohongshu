## 当前实现

视图在 `lib/ui/`，数据与交互状态在 `lib/data/`。使用 Flutter 的 ChangeNotifier 通知视图更新，使用 Navigator 管理页面。布局通过可用宽度切换为手机双列与大屏多列，未依赖 React Native 运行环境。

资料只包含一套教学服务端，当前版本可以独立离线浏览本地内容。没有接入小红书官方账号、数据接口或支付系统。

## 后续建议顺序

1. **账号和服务端**：设计自己的用户、笔记、评论、点赞、收藏、关注数据表；以 token 身份认证替换本地体验身份，服务端校验资源权限。
2. **媒体上传和分页**：把本地图片改为对象存储上传，在数据层接入发布、详情和分页接口。添加上传重试、游标分页、取消请求和刷新错误处理。
3. **本地存储升级**：当前 SharedPreferences 保存演示状态和少量 base64 图片。正式版本将图片放文件系统或对象存储，把记录放数据库；网页端可用 IndexedDB。避免大量图片占用偏好存储。
4. **消息**：接入会话服务、WebSocket、离线同步、已读状态和系统推送。当前发送的示例消息不会送达其他人。
5. **交易**：增加商品库存、订单、地址与服务端支付回调。当前购物袋只保存数量与计算合计。
6. **上线准备**：替换示例素材，完善内容举报、屏蔽、隐私与注销流程，设置应用标识、发布签名并进行 Android/iOS 真机测试。
