# 功能回归与输入修复

日期：2026-10-17。范围为当前 Flutter 本地体验版本。Android 15 / API 35 / x86_64 模拟器 `emulator-5556`，另检查 Windows 内置浏览器预览。

## 已修复

1. **桌面首页搜索不能直接输入**：移除拦截输入的 `IgnorePointer`，改为实际可编辑的搜索框；回车和搜索按钮均携带输入词进入结果页。
2. **键盘遮挡评论操作**：评论栏按系统键盘高度上移；支持多行、最多 500 字和键盘发送，保存期间防止重复发送。
3. **发布操作难以触达**：发布按钮固定在底部，键盘弹出时仍可见。标题“下一项”进入正文，正文支持换行，话题支持完成输入。
4. **小屏资料弹窗空间不足**：表单可滚动，昵称和简介拥有随弹窗生命周期释放的输入控制器；空昵称保留表单并显示错误。
5. **后续输入被异步发送清空**：评论和聊天只在保存成功、输入仍等于本次发送内容时清空，保留保存期间新输入的文本。
6. **编辑和导航边界**：仅填写话题也触发草稿保护；保存期间禁止重复发布及改动图片；切换底部导航收起键盘；发布成功后首页回到发现／推荐，显示新笔记。

- 静态分析无问题。
- 11 项测试通过：3 项数据测试、5 项输入回归、3 项不同尺寸导航。
- Android 一个完整端到端场景通过；工具输出包含清理阶段的 `+2`，不按两个独立场景计数。

- Web release 构建通过，本机配置输出 `build_temp/web`，预览服务已切换到新版。
- Windows 测试引擎并发运行时出现过进程意外退出；串行执行全部通过。复现命令因此固定使用 `--concurrency=1`。

端到端脚本在结束时恢复测试前的持久化内容。本轮还在应用外备份了模拟器原记录，用于重新安装普通包后恢复；相册测试素材只使用项目现有图片。未操作连接的实体手机。

## 代码整理回归

评论和发布共用 `KeyboardBar` 处理底部键盘避让；搜索页合并重复状态，发布页移除多余焦点对象和重复判断。组件测试与 Android 端到端测试共用触摸输入辅助方法，组件测试共用屏幕及本地数据初始化。整理后 11 项串行测试再次通过。
